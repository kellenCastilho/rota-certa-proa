# Rota Certa PRO — Sprint 2

Segunda sprint oficial do aplicativo.

## Novidades

- Busca por endereço, cliente, telefone, código e observações
- Filtros por status
- Filtros por prioridade
- Prioridades: urgente, alta, normal e baixa
- Nome do cliente
- Telefone do cliente
- Observações da entrega
- Cards com informações mais completas
- Layout responsivo dos filtros e do formulário
- Identidade visual, mapa, GPS, otimização e histórico preservados

## Como abrir

1. Extraia o ZIP.
2. Abra a pasta `rota-certa-pro-sprint-2` no VS Code.
3. Abra **Terminal → Novo Terminal**.
4. Execute:

```bash
npm install
npm run dev
```

5. Abra o endereço exibido, normalmente `http://localhost:5173`.
